# 🛡️ ScamCheck: AI-Powered Opportunity Verification

[![Python](https://img.shields.io/badge/Python-3.11-blue.svg)](https://python.org)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.109-green.svg)](https://fastapi.tiangolo.com)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**ScamCheck** is a lightweight, AI-assisted web application designed to detect and flag suspicious job offers, internship scams, and phishing attempts in real-time. Built for the "One-Man Army" hackathon track, it provides instant risk assessments with clear, visual indicators.

## 🚀 Features
- ⚡ **Instant Risk Scoring:** Analyzes text for urgency, suspicious payment requests, and generic greetings.
- 🎨 **Visual Risk Dashboard:** Clear Red/Yellow/Green indicators for immediate user understanding.
- 🔒 **Privacy-First:** All analysis is done locally or via secure API; no user data is stored.
- 📱 **Responsive UI:** Clean, modern interface built with Tailwind CSS that works on any device.

## 🛠️ Tech Stack
- **Backend:** Python, FastAPI, Uvicorn
- **Frontend:** HTML5, Vanilla JavaScript, Tailwind CSS (via CDN)
- **AI/Logic:** Heuristic NLP analysis (with Gemini AI integration ready)
